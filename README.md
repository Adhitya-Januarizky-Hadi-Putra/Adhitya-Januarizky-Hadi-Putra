## 🚀 Featured Projects

### 📷 [Interactive Image Enhancement App](https://github.com/Adhitya-Januarizky-Hadi-Putra/Interactive-Image-Enhancement-App)
> A comprehensive Python application for evaluating and comparing cutting-edge digital image enhancement methods

**✨ Key Features:**
- ✨ Intensity Transformation - Advanced pixel value manipulation
- 📊 Histogram Equalization - Enhanced contrast and brightness
- 🎯 Histogram Matching - Precise color distribution matching
- 🔍 CLAHE - Contrast Limited Adaptive Histogram Equalization
- 🎨 Real-time visualization and side-by-side comparison tools
- 📈 Performance metrics and statistical analysis

**Tech Stack:** Python | OpenCV | NumPy | Tkinter | PIL  
**License:** MIT | **Status:** Active Development
